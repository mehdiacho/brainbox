# History

Repositories folded into this one. Each keeps its full commit history under
`history/<name>/`. To read those commits, find the "Fold <name>" commit and run
`git log <that commit>^2`. The original repository is archived on GitHub, never deleted.

- **IdeaSpace** (2026-10-18 to 2026-10-18): `history/IdeaSpace/`, original at https://github.com/mehdiacho/IdeaSpace (archived).
- **Idea-Pad** (2024-07-13 to 2024-07-13): `history/Idea-Pad/`, original at https://github.com/mehdiacho/Idea-Pad (archived).
